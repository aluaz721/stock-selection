# frontend

Next.js dashboard for the ML Stock Selection pipeline — see the
[repo root README](../README.md) for what this project is.

Reads `../data/predictions/{latest,history}.json` (copied into
`public/data/` by `scripts/sync-data.mjs`, wired as `predev`/`prebuild`)
and statically renders the backtest summary, performance chart, and
today's picks. No backend of its own — the data is pipeline output,
regenerated by `python -m app.reporting.build_frontend_data` at the repo
root.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production build, static output
```
